Two-state pressed button with `aria-pressed` ([shadcn Toggle](https://ui.shadcn.com/docs/components/toggle)). Variants: `default`, `outline`. Sizes: `sm`, `default`, `lg`. Included in `@stdScripts`.

```blade
<x-std::toggle aria-label="Toggle italic">Italic</x-std::toggle>
<x-std::toggle variant="outline" :pressed="true">Bold</x-std::toggle>
<x-std::toggle size="sm" variant="outline">Small</x-std::toggle>
```
